# Taskora – Smart To-Do List Web App ✅

Taskora is a modern and user-friendly To-Do List web app designed to help users organize daily tasks, manage priorities, and track their progress efficiently.

## ✨ Features

* Add, edit, and delete tasks
* Mark tasks as completed
* Set task priorities and due dates
* Search and filter tasks
* Organize tasks into categories
* View today's and upcoming tasks
* Track progress with a dashboard
* Save tasks using Local Storage
* Responsive design for mobile and desktop
* Dark and light mode

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/iimehruu17-pixel/Syntecxhub_ToDoList_App.git
   ```
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or use the Live Server extension.

## 🎯 Project Purpose

This project was created to practice frontend development, JavaScript functionality, task management, and responsive UI design.
